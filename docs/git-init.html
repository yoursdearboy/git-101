Глава 5 Создание репозитория

Git может отслеживать изменения в любой папке на вашем компьютере. Для этого нужно инициализировать в ней Git репозиторий. Репозиторий — это скрытая подпапка .git, в которой хранятся версии проекта и информация об изменениях. Всё необходимое для работы Git содержится непосредственно в ней.

Проект для этого курса уже создан в конце курса R. Откройте Positron и на экране Welcome выберите Open Folder, затем укажите папку проекта r-course. Не создавайте новый проект, не переносите и не переименовывайте накопленные файлы.

Убедитесь в том, что проект загружен: в панели Explorer должна быть открыта папка с файлами проекта, в том числе с папкой data. Откройте Source Control на панели активности. Если там уже перечислены файлы проекта, репозиторий готов.

Окно Positron с открытой папкой r-course: в Explorer видны накопленные файлы и папка data, а в Source Control перечислены незафиксированные файлы. Команда подготовки: python3 bin/create_course_project.py /tmp/git-course-starter –state starter

Когда в Positron открыта папка проекта, R и Git ищут файлы в ней — это так называемая рабочая папка или рабочая область.

Подробнее про поиск и адреса файлов.

На разных компьютерах, например у разных участников, проект может находиться в разных местах. У пользователя с именем mjordan это может быть /Users/mjordan/penguins, а у пользователя scruz допустим
C:\Users\scruz\penguins.

Если в документе использовать полный адрес файла, например:

read.csv("/Users/mjordan/r-course/data/penguins.csv")

то он будет работать только у пользователя mjordan. У других полный адрес будет отличаться, и код «сломается». Чтобы он работал у всех, нужно указывать адрес файла относительно рабочей папки.

read.csv("data/penguins.csv")

Рассмотрим служебные файлы проекта:

  • .gitignore — содержит список файлов, которые Git не будет отслеживать; о том, зачем это нужно и как настроить смотри в отдельном разделе
  • .git — репозиторий; это скрытая папка, в которой Git будет хранить версии проекта

Если вместо списка файлов Source Control показывает кнопку Initialize Repository, нажмите её один раз. Positron создаст репозиторий в уже существующей папке, не меняя остальные файлы.

Итак, у нас есть проект — папка, в которой мы будем работать, и внутри нее Git репозиторий — скрытая папка, в которой будут храниться версии проекта. Приступим к созданию первой версии.

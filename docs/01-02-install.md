# Установка Git {#install-git}

Positron предоставляет интерфейс Source Control, но использует Git, установленный в операционной системе. Если Git не найден, Source Control покажет предложение его установить. Такое поведение описано в официальной главе [Git Version Control](https://positron.posit.co/git.html).

## Проверка

Откройте встроенный терминал командой **Terminal: Create New Terminal** из палитры команд и выполните:

```sh
git --version
```

Если команда вывела строку вида `git version 2.45.2`, установка готова. Конкретный номер может отличаться.

## Если Git не установлен

- **Windows:** установите [Git for Windows](https://git-scm.com/download/win), оставив параметры установщика по умолчанию.
- **macOS:** установите [Xcode Command Line Tools](https://developer.apple.com/xcode/resources/) по предложению системы после команды `git --version` или установите Git с [официальной страницы](https://git-scm.com/download/mac).
- **Linux:** используйте менеджер пакетов своего дистрибутива; команды приведены в [официальной инструкции Git](https://git-scm.com/download/linux).

После установки полностью перезапустите Positron и снова выполните `git --version`.

::: {.callout .callout-warning}
Не скачивайте отдельные графические клиенты Git для прохождения курса. Они могут пригодиться позже, но названия действий и расположение элементов будут отличаться от Positron.
:::

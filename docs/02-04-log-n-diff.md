# История и различия {#history-diff}

Разверните **Source Control Graph** в Source Control. В нём видны коммиты текущей ветки `main`.

Выберите коммит `Сохранил гистограмму длины клюва`. Под ним появится список изменённых файлов. Выберите `paper.qmd`, чтобы открыть diff именно для этого коммита.

![Source Control Graph с тремя учебными коммитами и открытым diff файла paper.qmd для коммита с гистограммой]()

В diff удалённые строки отмечены красным, добавленные — зелёным. Git сравнивает строки, поэтому даже изменение одного символа может выглядеть как удаление старой строки и добавление новой.

Для истории одного файла откройте `paper.qmd`, затем разверните **Timeline** в Explorer. Там можно выбрать прежний коммит и посмотреть, как менялся только этот файл.

## Рабочая папка, индекс и коммит

Эти три состояния полезно различать:

| Состояние | Что содержит |
|---|---|
| Рабочая папка | Сохранённые на диске файлы, включая незаконченные изменения |
| Индекс | Только изменения, выбранные для следующего коммита |
| Последний коммит | Уже записанный снимок проекта |

Кнопка `+` переносит изменение из рабочей папки в индекс. Кнопка `−` у **Staged Changes** убирает его из индекса, но не удаляет из файла. **Commit** записывает содержимое индекса в историю.

Официальное руководство [Staging and committing changes](https://code.visualstudio.com/docs/sourcecontrol/staging-commits) использует эту же модель.

# Pull Request {#pr}

Pull Request --- это механизм GitHub для слияния веток загруженных в удаленный репозиторий, позволяющий просмотреть, обсудить и проверить предлагаемые изменения перед слиянием. Похожий механизм существует и на других платформах.

Орнитолог проходящий мимо нашего репозитория обратит внимание, что длину клюва пингвина лучше рассматривать в зависимости от пола. Он даже может предложить необходимые изменения при помощи Pull Request.

Создайте ветку с названием `adjust-by-sex`: нажмите название текущей ветки в строке состояния Positron и выберите [Create new branch…]{.figtext}. Убедитесь, что вместо названия ветки по умолчанию `main` выводится название созданной ветки `adjust-by-sex`.

![Строка состояния Positron после создания ветки: показано название adjust-by-sex. Подготовьте опубликованное состояние merged и создайте ветку adjust-by-sex]()

Отредактируйте документ `paper.qmd`, добавив пол в код для построения ящика с усами. Код приведен ниже, не забывайте, что вы можете сравнить изменения по сравнению с оригиналом, выбрав файл на панели [Source Control]{.figtext}.


``` r
data <- read.csv("data/penguins.csv")
x <- data$bill_len
g <- data$sex

png("out/penguins-boxplot.png")
boxplot(x ~ g, xlab = "Sex", ylab = "Bill length, mm")
dev.off()
```

Сохраните документ и выполните блок R.
Создайте коммит, включив в него `paper.qmd` и обновленную диаграмму `out/penguins-boxplot.png`.

![Source Control перед коммитом в adjust-by-sex: изменены paper.qmd и out/penguins-boxplot.png. Подготовьте ветку adjust-by-sex, внесите изменения по заданию и добавьте оба файла в индекс]()

После создания коммита выберите [Publish Branch]{.figtext} на панели [Source Control]{.figtext}. Так как у вас полные права на редактирование репозитория, то новая ветка будет загружена на GitHub. Прохожему орнитологу пришлось бы создать свою копию репозитория или просить дать доступ средствами GitHub.

Перейдите на страницу репозитория в GitHub и убедитесь, что ветка была загружена и содержит сделанные измнения, для этого выберите ее в выпадающем меню появляющемся при нажатии кнопки с названием ветки [main]{.figtext}.

![Страница GitHub с выбранной веткой adjust-by-sex и обновлённым графиком. Команда подготовки: python3 bin/create_course_project.py /tmp/git-course-pr --state github-pr --repo OWNER/NAME --visibility public]()

При просмотре ветки отличной от основной, GitHub предложит создать из нее **Pull Request** --- предложение автору репозитория слить изменения из этой ветки. Нажмите кнопку [Contribute]{.figtext} и в выпадающем меню выберите [Open pull request]{.figtext}.

![Меню Contribute на GitHub с действием Open pull request. Подготовьте состояние github-pr и откройте ветку adjust-by-sex на GitHub]()

GitHub предложит ввести заголовок и описание предлагаемых изменений, правило хорошего тона кратко описать причину изменений и суть предлагаемого решения. А также, прокрутите страницу создания Pull Request и проверьте изменения, которые вы предлагаете, после чего нажмите кнопку [Create pull Request]{.figtext} под полем с описанием.

![Форма создания pull request на GitHub: заполнены заголовок и описание, ниже показан diff. В состоянии github-pr выберите Contribute → Open pull request]()

На странице Pull Request владельцу репозитория доступна опция слить предложенные изменения.
Нажмите кнопку [Merge pull request]{.figtext} внизу страницы.
В открывшемся окне GitHub предложить ввести текст коммита, как если бы мы делали слияние ветки в терминале. Оставьте или измените текст и нажмите кнопку [Confirm merge]{.figtext}
После успешного слияния ветку можно удалить.

![Страница pull request перед слиянием: доступна кнопка Merge pull request. Создайте pull request из состояния github-pr и откройте его страницу]()

![Подтверждение merge-коммита на GitHub. На странице pull request нажмите Merge pull request]()

![Pull request после успешного слияния и предложение удалить ветку. Команда подготовки: python3 bin/create_course_project.py /tmp/git-course-github-merged --state github-merged --repo OWNER/NAME --visibility public]()

Вернемся к нашему проекту в Positron.
Слияние было выполнено онлайн на GitHub, а значит необходимо загрузить изменения в наш локальный репозиторий, т.е. сделать pull.
Переключитесь на ветку `main` при помощи строки состояния и выберите [Pull]{.figtext} на панели [Source Control]{.figtext}.
Убедитесь, что теперь ветка `main` содержит актуальные изменения в файлах `paper.qmd` и `out/penguins-boxplot.png`.

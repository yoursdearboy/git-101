Глава 3 Установка

3.1 Проверьте наличие Git

Откройте Rstudio. В верхнем меню выберите Tools → Terminal → New Terminal. В терминале введите команду git и нажмите клавишу Enter.

Если вы видите результат как на скриншоте ниже, то Git установлен.
Иначе нужно его установить — см. инструкцию для вашей операционной системы ниже. После установки перезапустите RStudio и повторите проверку.

3.2 Windows

Загрузите инсталлятор по ссылке git-scm.com/downloads/win (используйте Standalone, а не Portable версию, если в этом нет необходимости). Далее следуйте инструкциям на экране, можете везде оставить опции, выбранные по умолчанию.

3.3 Mac OS

Вариант 1. Git входит в инструменты разработчика от Apple, которые предоставляются бесплатно. Для установки введите в терминал следующую команду:

xcode-select --install

В появившемся окне нажмите кнопку Install.

Вариант 2. Последнюю версию Git можно установить при помощи стороннего менеджера программ Homebrew. Если он у вас установлен, введите в терминал следующую команду:

brew install git

3.4 Linux

Для Ubuntu или Debian:

sudo apt-get update
sudo apt-get install git

Для других дистрибутивов см. git-scm.com/downloads/linux (не забудьте запустить команду с правами администратора, т.е. начав с sudo, как в примере выше).

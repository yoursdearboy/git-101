Глава 17 Клонирование

Клонирование создаёт новую локальную папку из удалённого репозитория. Вместе с файлами загружаются коммиты и ветки, а Git автоматически добавляет remote origin.

Не клонируйте репозиторий внутрь уже открытого r-course. Для проверки используйте другую родительскую папку.

  1. Откройте новое окно Positron без проекта.
  2. Выполните Workspaces: New Folder from Git… из палитры команд.
  3. Выберите Clone from GitHub и свой репозиторий r-course.
  4. Укажите родительскую папку, например projects-copy.
  5. После загрузки нажмите Open.
Окно Workspaces: New Folder from Git со списком репозиториев GitHub и выбранным r-course

Откройте Source Control Graph и paper.qmd. История и код должны совпадать с первым проектом.

Не редактируйте обе копии одновременно без необходимости. Это два независимых рабочих каталога: изменения попадут друг к другу только через Push и Pull.

Если Positron спрашивает, доверяете ли вы содержимому, подтверждайте доверие только для своего репозитория или известного источника. Открытие чужого проекта ещё не запускает код, но дальнейшее выполнение файлов может это сделать.

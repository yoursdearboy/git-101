# Клонирование репозитория (clone) {#git-clone}

Частый способ начала работы над проектом.
Хотя, может это будет в разделе про GitHub.
Или хотя бы после раздела `commit`.
Хотя как-то получить скрипт для проверки им нужно.

Открой новый терминал:

```sh
git clone https://github.com/yoursdearboy/gitfun-demo
```

Посмотрим содержимое:

```sh
cd gitfun-demo
ls -A
# check.sh
```

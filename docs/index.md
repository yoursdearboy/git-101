# Основы Git

Привет!
Перед вами краткое руководство по работе с системой контроля версий Git и сервисом GitHub, написанное для биоинформатиков, статистиков и других специалистов занимающихся анализом данных.

::: {style="float: left; clear: both; width: 200px; margin-right: 20px;"}
![](./img/git-logo.png){width=200px}
:::

Эти инструменты пригодятся вам во время курса и при выполнении учебных проектов, хотя их настоящая ценность проявляется в ежедневной работе.
Git помогает организовать процесс анализа данных, отслеживать изменения, наладить совместную работу и обеспечить воспроизводимость исследований.
Он используется не только в крупных компаниях, но и небольшими командами и отдельными специалистами.

Git очень простой инструмент, можно даже сказать, примитивный или глупый
^[именно это означает сленговое слово *git* в английском],
поэтому освоить его не составит труда.
Однако спешу вас заверить, что даже те, кто сейчас эффективно использует Git, в первое время сталкивались с проблемами.
Умение работать с Git — это практический навык, который приходит с опытом.

::: {style="float: right; width: 250px"}
![](./img/penguins2.png){width=250px}
:::

Существует множество руководств и даже книг, ссылки на которые есть в последней главе,
но предпочтительный способ изучения --- больше использовать Git на практике.
Поэтому от главы к главе выполняйте инструкции и команды приведенные в курсе.
В качестве примера мы будем использовать данные о длине клюва пингвинов с антарктической станции Палмер.
К концу у вас должен получиться полноценный проект с очень небольшим анализом.

Курс состоит из четырех частей, рассчитанных в среднем на 1-2 часа.
В первой части мы установим и настроим Git.
Во второй части научимся записывать и просматривать историю версий.
В третьей части научимся создавать альтернативные версии --- это важная функция Git и основа для совместной работы.
В последней четвёртой части зарегистрируемся на GitHub, выложим наш проект и научимся синхронизировать изменения с сервером, чтобы работать в команде.
Этих навыков достаточно для работы с большинством реальных проектов.



[В предпоследней главе](#faq) приведены советы, которые помогут эффективней работать с Git без страха что-то сломать. А в [последней главе](#references) вы найдете ссылки на другие руководства, книги и полезные ресурсы.

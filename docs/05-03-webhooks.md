# Webhooks {#webhooks}

Webhook позволяет GitHub отправить HTTP-запрос внешнему сервису после события: push, создания pull request или слияния. Так запускают уведомления и автоматические проверки.

Для настройки нужен готовый HTTPS-адрес сервиса. Не указывайте случайный сайт: содержимое запроса может включать имена репозитория, веток и участников.

1. Откройте репозиторий на GitHub.
2. Перейдите **Settings → Webhooks → Add webhook**.
3. Вставьте адрес в **Payload URL**.
4. Выберите `application/json`.
5. Добавьте отдельный случайный **Secret**, если принимающий сервис умеет проверять подпись.
6. Выберите **Let me select individual events** и оставьте **Pull requests**.
7. Нажмите **Add webhook**.

![Страница GitHub Add webhook: заполнен Payload URL, content type application/json, выбран Pull requests, секрет скрыт]()

В разделе **Recent Deliveries** откройте тестовую доставку. Код `2xx` означает, что сервис принял запрос. Код `4xx` обычно указывает на неверный адрес или авторизацию, `5xx` — на ошибку принимающего сервиса.

::: {.callout .callout-warning}
Webhook может запускать действия во внешней системе. Проверяйте адрес и минимально необходимый набор событий. Не записывайте secret в репозиторий и не показывайте его на скриншоте.
:::

Для преподавателя генератор проекта умеет создать такой webhook через `gh` в состоянии `github-webhook`; студенту достаточно один раз пройти настройку в интерфейсе и проверить доставку.

Глава 10 Переключение веток

Нажмите boxplot в строке состояния и выберите main. Эта операция называется переключением, а в терминах Git — checkout или switch.

Откройте paper.qmd и папку out. В main снова должна быть гистограмма и не должно быть нового боксплота. Git привёл рабочую папку к коммиту выбранной ветки.

Ветка main после переключения: paper.qmd содержит hist(), в out виден penguins-hist.png

10.1 Защита незаписанной работы

В paper.qmd добавьте подпись оси:

hist(x, breaks = seq(30, 60, 2), xlab = "Bill length, mm")

Сохраните файл, но пока не создавайте коммит. Попробуйте переключиться на boxplot.

Если переключение перезапишет изменённые строки, Git остановит операцию и предложит сначала сохранить работу. Это защитное поведение: незакоммиченные изменения не потеряны, вы по-прежнему на main.

Уведомление Positron об отказе переключить ветку из-за незакоммиченных изменений в paper.qmd

Вернитесь в Source Control, проверьте diff и создайте коммит Добавил подпись оси гистограммы. После этого переключитесь на boxplot и обратно на main, чтобы проверить обе версии.

Если нужно временно убрать незаконченные изменения без коммита, используйте Git: Stash (Include Untracked). Для основного упражнения stash не нужен.

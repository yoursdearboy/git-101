Глава 19 Частые ситуации

19.1 Source Control не показывает проект

Убедитесь, что в Positron открыта именно папка r-course, а не отдельный файл. Затем выполните Developer: Reload Window. Если репозитория действительно нет, появится Initialize Repository.

Для диагностики откройте Git: Show Git Output. Последняя строка обычно содержит команду и причину ошибки. Перед отправкой лога удалите из него токены и приватные адреса.

19.2 Коммит не содержит файл

Коммит получает только Staged Changes. Найдите файл в Changes, нажмите +, проверьте diff и создайте новый коммит. Не нужно удалять предыдущий коммит ради пропущенного файла.

19.3 В коммит попал лишний файл

Если коммит ещё не отправлен и вы работаете один, откройте в Source Control меню More Actions (…) → Commit → Undo Last Commit. Изменения останутся в Staged Changes. Исправьте индекс и создайте коммит снова.

Если коммит уже отправлен или его могли скачать коллеги, не переписывайте историю. Сделайте новый коммит, который удаляет или исправляет лишнее.

19.4 Нужно временно переключиться

Сохраните законченную часть коммитом. Для незаконченной используйте Git: Stash (Include Untracked), затем переключитесь. Вернуть выбранный stash можно командой Git: Pop Stash….

19.5 Конфликт возник при Pull

Это то же слияние, что в главе 11. Откройте файлы из Merge Changes, соберите осмысленный Result, нажмите Complete Merge и создайте коммит. После этого повторите Push.

19.6 Опасные операции

Команды force push, hard reset, удаление неслитой ветки и переписывание опубликованной истории могут стереть доступ к чужим коммитам.

Не используйте Force Push, git reset --hard и удаление неслитых веток в командном проекте без явного согласования. Сначала создайте резервную ветку или попросите преподавателя помочь.

19.7 Данные и секреты

Git хорошо подходит для кода и небольших учебных данных. Большие файлы быстро раздувают историю, а удалённый из последнего коммита секрет может сохраниться в старых версиях.

Перед первым коммитом добавляйте в .gitignore временные файлы, локальные настройки и секреты. Если секрет уже отправлен, сначала отзовите его у провайдера; одного удаления файла недостаточно.

# Итог работы с ветками {#branches-conclusion}

Разверните Source Control Graph. От общего коммита расходятся `main` и `boxplot`, а коммит слияния снова соединяет линии.

![Source Control Graph после слияния: видны расхождение main и boxplot и merge-коммит в main]()

Теперь вы умеете:

- создавать ветку командой **Git: Create Branch**;
- переключаться через индикатор ветки или **Git: Checkout to**;
- объединять ветки командой **Git: Merge Branch**;
- разрешать конфликт в трёхстороннем редакторе;
- отменять незавершённое слияние командой **Git: Abort Merge**.

После проверки слитую локальную ветку можно удалить: переключитесь на `main`, выполните **Git: Delete Branch** и выберите `boxplot`.

::: {.callout .callout-warning}
Не удаляйте ветку, пока её изменения не слиты и не стали ненужными. Удаление несохранённой линии истории сложнее отменить, чем обычное редактирование файла.
:::

В следующей части вынесем репозиторий на GitHub и повторим этот процесс как предложение изменений для коллег.

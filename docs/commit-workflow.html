Глава 7 Рабочий цикл

Теперь начнём отдельный анализ для Git-курса. Каждая небольшая законченная задача станет коммитом:

  1. изменить и сохранить файл;
  2. открыть diff и проверить изменение;
  3. добавить нужные файлы в индекс;
  4. записать коммит;
  5. убедиться, что Source Control снова пуст.

7.1 Документ Quarto

Создайте в корне проекта файл paper.qmd. Накопленные .R-скрипты остаются без изменений, но весь новый код пишем в Quarto.

Добавьте настройки и первый блок R:

---
title: "Длина клюва пингвинов"
format: html
---
data <- read.csv("data/penguins.csv")
x <- data$bill_len |> na.omit()
x

Путь начинается от корня проекта. Данные уже находятся в data, поэтому ничего скачивать и перекладывать не нужно. В новом коде используем базовую трубу |>.

Выполните блок в текущей R-сессии. Positron передаст код из документа Quarto в Console. Убедитесь, что вектор x создан без ошибки.

Открытый paper.qmd после выполнения блока: в Console виден результат импорта data/penguins.csv

Сохраните файл, проверьте diff и создайте коммит Добавил импорт данных в paper.qmd.

7.2 Гистограмма

Замените блок кода на следующий:

data <- read.csv("data/penguins.csv")
x <- data$bill_len |> na.omit()

png("out/penguins-hist.png")
hist(x, breaks = seq(30, 60, 2))
dev.off()

Выполните блок. В папке out появится penguins-hist.png.

В Source Control выберите paper.qmd и проверьте добавленные строки. Затем добавьте в индекс paper.qmd и out/penguins-hist.png, но не остальные случайные изменения. Создайте коммит Сохранил гистограмму длины клюва.

Source Control перед коммитом гистограммы: в Staged Changes находятся только paper.qmd и out/penguins-hist.png

Теперь у проекта есть исходная версия, импорт данных и готовый график в трёх отдельных коммитах.

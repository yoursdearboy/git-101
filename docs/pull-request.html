Глава 16 Pull request

Pull request — предложение объединить одну ветку с другой на GitHub. Перед слиянием коллеги могут посмотреть diff, обсудить решение и запустить проверки.

16.1 Изменение в ветке

Создайте от актуальной main ветку adjust-by-sex. В paper.qmd замените блок кода:

data <- read.csv("data/penguins.csv")
x <- data$bill_len
g <- data$sex

png("out/penguins-boxplot.png")
boxplot(x ~ g, xlab = "Sex", ylab = "Bill length, mm")
dev.off()

Соберите документ, проверьте обновлённый график и создайте коммит Сгруппировал пингвинов по полу.

Нажмите Publish Branch. Это создаст adjust-by-sex в origin и свяжет локальную ветку с удалённой.

Ветка adjust-by-sex после Publish Branch: Source Control Graph показывает локальную и удалённую ветки на одном коммите

16.2 Создание предложения

Откройте представление Pull Requests на панели активности. Нажмите Create Pull Request или выполните команду GitHub Pull Requests: Create Pull Request.

Выберите:

  • базовый репозиторий — ваш r-course;
  • базовую ветку — main;
  • ветку с изменением — adjust-by-sex;
  • заголовок — Сгруппировал пингвинов по полу.

В описании объясните причину: распределение длины клюва теперь показано отдельно для каждого пола. Перед созданием откройте список файлов и проверьте diff.

Форма Create Pull Request в Positron: base main, compare adjust-by-sex, заполнены заголовок и описание

Нажмите Create. Откроется режим просмотра pull request. Здесь можно оставить комментарий к строке, запросить проверку и увидеть обсуждение.

16.3 Слияние

Нажмите Merge только после проверки файлов. Выберите обычное создание merge-коммита, затем подтвердите операцию. После успешного слияния удалите ветку, когда Positron предложит это сделать.

Переключитесь на локальную main и выполните Pull. Убедитесь, что paper.qmd содержит группировку по полу, а Source Control Graph — коммит слияния с GitHub.

# Публикация репозитория {#publish-github}

Убедитесь, что выбрана ветка `main`, Source Control пуст и последний коммит — `Слил ветку boxplot`.

В Source Control нажмите **Publish to GitHub**. Если кнопка не видна, откройте палитру команд и найдите **Publish to GitHub**.

Выберите имя репозитория, например `r-course`, и доступ **Private repository**. Для учебного проекта приватный режим безопаснее: открыть репозиторий позже можно в настройках GitHub.

Если Positron предложит выбрать файлы, оставьте все уже отслеживаемые файлы. В проекте не должно быть секретов.

![Диалог Publish to GitHub с именем r-course и выбранным вариантом Private repository]()

Positron выполнит три связанных действия:

1. создаст репозиторий на GitHub;
2. добавит его как удалённый репозиторий `origin`;
3. отправит коммиты ветки `main`.

После публикации откройте созданный репозиторий на GitHub и сравните список файлов с Explorer. Убедитесь, что на сайте есть `paper.qmd`, папка `data` и история коммитов.

**Удалённый репозиторий** (remote) — адрес другой копии проекта. Имя `origin` условное, но Git назначает его основной удалённой копии при публикации и клонировании.

::: {.callout .callout-info}
GitHub не выполняет код Quarto при обычной отправке. Файлы и история появятся на сервере, но готовый сайт требует отдельной настройки публикации.
:::

Глава 13 Аккаунт и вход

Git хранит историю на вашем компьютере. GitHub хранит копию репозитория на сервере, поэтому проект можно открыть с другого устройства, показать преподавателю и обсудить изменения с коллегами.

Создайте аккаунт на github.com, если его ещё нет. Имя пользователя станет частью адресов репозиториев, поэтому лучше использовать короткое имя латиницей.

Positron включает расширения GitHub и GitHub Pull Requests and Issues. При первой публикации или отправке изменений редактор предложит войти. Выберите Sign in with GitHub, подтвердите открытие браузера и разрешите доступ.

Positron показывает запрос Sign in with GitHub перед первой публикацией репозитория

После подтверждения вернитесь в Positron. Не создавайте classic personal access token для этого упражнения: обычный путь входа проходит через браузер.

Никому не отправляйте пароли, токены, приватные ключи и секреты webhook. Не добавляйте их в .qmd, .R, .env или другие файлы репозитория.

13.1 Git и GitHub — разные системы

Коммит, ветка и слияние работают в Git без GitHub. GitHub добавляет удалённый репозиторий, права доступа, pull request, обсуждения и автоматические проверки.

Если сайт GitHub недоступен, локальные коммиты продолжают работать. Когда связь восстановится, их можно отправить на сервер.

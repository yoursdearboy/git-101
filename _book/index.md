# Введение в Git

Привет!
Перед вами краткое руководство по работе с системой контроля версий Git и сервисом для разработчиков GitHub.

![](./img/git-logo.png){width=300px}

Инструменты изначально созданные для разработчиков оказались полезными и даже незаменимыми в работе биоинформатика, статистика и других специалистов, вовлеченных в проведение и анализ научных экспериментов.  
Они пригодятся вам в рамках курса и при выполнении учебных проектов, хотя их настоящая ценность проявляется в прикладной работе.
Git применяется не только крупными подразделениями в компаниях, но и небольшими командами и конечно отдельными специалистами.
Он позволяет эффективно управлять процессом анализа данных, отслеживать изменения, организовывать совместню работу и обеспечивать воспроизводимость экспериментов.

Сам по себе Git очень простой инструмент, даже можно сказать примитивный или глупый
^[именно это означает сленговое слово *git* в английском].
Освоить его не составит труда. Мы рассмотрим несколько ключевых понятий, которые будут достаточны для большинства задач.
Однако спешу вас заверить, что даже те, кто сейчас эффективно использует Git, в первое время сталкивались с проблемами --- это абсолютно нормальная ситуация.
И я хочу подчеркнуть, что работа с Git --- это очень практический навык, который приобретается с опытом.
Существует множество инструкций и даже книг, ссылки на которые есть [в последней главе](#references),
но предпочтительный способ изучения --- это последовательно выполнять команды приведеннные в этой инструкции

```
в таких вот разделах
```

и больше использовать Git в своей работе.
[В предпоследней главе](#faq) приведены некоторые best practices, которые помогут делать это эффективно и без страха что-то сломать.

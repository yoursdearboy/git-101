# Настройка {#setup}

Есть много способов работы с Git:

- Через терминал --- при помощи команды `git`, которую мы запустили в предыдущей главе;
- Через графический интерфейс --- либо встроенный в программы для разработки (например, [RStudio](https://docs.posit.co/ide/user/ide/guide/tools/version-control.html), [Pycharm](https://www.jetbrains.com/help/pycharm/using-git-integration.html), [VS Code](https://code.visualstudio.com/docs/sourcecontrol/overview)), либо самостоятельный ([GitHub Desktop](https://github.com/apps/desktop), [GitKraken](https://www.gitkraken.com), [и так далее](https://git-scm.com/downloads/guis));
- Через веб-интерфейс (например, отдельные файлы можно редактировать прямо на сайте GitHub).

Не обязательно выбирать какой-то один из способов. В этой инструкции, как и в повседневной практике большинства пользователей, мы будем одновременно работать с Git и средствами RStudio, и в терминале.

При этом универсальным и наиболее распространенным способом является терминал. Команды для него вы встретите в документации и в интернете, ими легче поделиться и использовать в скриптах.

Первое что нам необходимо сделать --- сообщить Git свое имя и email, чтобы он мог верно записать, кто вносит изменения.

Для этого откройте терминал встроенный в RStudio [как мы делали в предыдущей главе](#terminal)
<!-- ^[В верхнем меню выберите **Tools → Terminal → New Terminal**] -->
(при желании можете использовать любой другой).
В терминале выполните следующие команды, заменив **Your Name** на свое имя и **your@email.com** на свой e-mail.

```sh
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

Обратите внимание на опцию `--global`, которая означает ...

А также заранее настроим способ объединения изменений, чтобы не возвращаться к этому позже:

```sh
git config --global pull.rebase false
```

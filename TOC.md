1. Подготовка
   - зачем проекту Git;
   - установка Git;
   - имя автора.
2. Коммиты
   - открытие накопленного проекта `r-course`;
   - исходный коммит без преобразований;
   - рабочий цикл в `paper.qmd`;

3. Ветки
   - ветка `boxplot`;
   - переключение;
   - конфликт и трёхстороннее слияние.
4. GitHub
   - публикация;
   - Push, Pull и Sync Changes;
   - pull request `adjust-by-sex`;
   - клонирование.
5. Дополнительно
   - частые ситуации и опасные операции;
